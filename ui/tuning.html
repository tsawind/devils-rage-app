Client tuning

Setting up a new group of clients? Use New launch group: it does everything on one page, in a profile folder of its own. This page tunes sound and graphics on profiles you already have.

1 · Pick a preset (or start from one and adjust)

2 · Adjust the levers

Every EVE setting, in the same order as EVE's own Settings window (click a section to open it). Ticked rows are written; unticked rows stay as each client has them. Rows marked by hand EVE keeps in its own per-account files, which the app doesn't touch: set them once in EVE for each account. “Now” is the first picked profile's current value.

3 · Pick the clients

4 · Apply

Close the clients first; restore any time from Client settings → Backups.
