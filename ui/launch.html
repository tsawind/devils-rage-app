Launch groups

A group is a set of characters you run together, in order. Open launcher starts the official EVE launcher so it can sign in and launch (the app never holds your passwords). Set a pedal / hotkey and tapping it brings the next client in the group to the front — like EVE-O Preview. Add Login screens to a group to cycle clients still sitting at character select.

Can't find your EVE launcher yet. Set its path in Settings (point to eve-online.exe).

Bright = open now · dim = not running · green ring = the client in front
