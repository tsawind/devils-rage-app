Setups

look only · changes nothing

Step 1 of the setup plan: this page reads every EVE client profile and shows where each client opens, what each account's keys, overview and effects are, and which client size each character's windows were arranged for. Same letter = identical. Nothing is changed here; EVE saves a client's settings when it closes, so this is how things stood at each client's last close.

1 · Where each client opens

Every spot a profile opens a window at. Profiles that share a spot open on top of each other (a stack).

2 · Accounts

One row per account file. An account that has run in more than one profile has a copy in each, and the copies can drift apart.

3 · Characters

Windows each character has placed, and the client size they were placed at (a layout fits a client of that size; 2131×1137 is 1918×1024 at 90% UI scale).

4 · Compare setups

Pick 2 to 8 characters. Each is read with its own character file and the account file beside it, and only the settings that differ are shown.
